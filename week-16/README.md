# Week 16 — Final Project / Final Test

## Learning outcome

Design, implement, test, demonstrate, and defend a complete object-oriented solution.

## Final workflow

```text
Requirement
  ↓
OOA
  ↓
OOD
  ↓
OOP
  ↓
OOT
  ↓
Demo / Viva
```

## Expected evidence

- candidate classes with clear responsibilities
- appropriate state and behavior
- meaningful object relationships
- inheritance/polymorphism where justified
- encapsulation and valid object state
- exception/contract handling
- executable Python implementation
- tests for independent and collaborating classes
- explanation of design decisions

See [Final Project](../assessments/final-project/README.md) for the project rubric.
