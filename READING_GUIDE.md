# Reading & Reference Access Guide

The course has exactly two formal references:

1. Inggriani Liem. *Diktat Kuliah Pemrograman Berorientasi Objek*. Departemen Teknik Informatika ITB, 2003.
2. OpenStax. *Introduction to Python Programming*. 2024.

See [Reference Map](REFERENCE_MAP.md) for module-by-module alignment and [Source Boundary](SOURCE_BOUNDARY.md) for the formal source policy.

## Do I need both references before starting?

No.

The repository is designed to provide the learning path, explanations, executable examples, exercises, assessments, and mastery feedback needed to progress through the course.

The references serve two additional purposes:

- provide traceability for the concepts used by the course;
- give learners a deeper or alternate explanation when they want one.

A learner should not be blocked from starting Module 1 merely because one external reference is not immediately available.

## OpenStax — free official access

*Introduction to Python Programming* is available free from OpenStax:

https://openstax.org/books/introduction-python-programming/pages/1-introduction

OpenStax provides web access and a PDF option. The course uses it primarily for Python-facing implementation material.

When a module names an OpenStax section, use that section as supporting reading rather than as a separate prerequisite course.

## Inggriani Liem — conceptual reference

The 2003 *Diktat Kuliah Pemrograman Berorientasi Objek* is used primarily for conceptual OOP terminology, modelling, contracts, analysis/design/testing, and reusability concepts.

The repository does not bundle or mirror a copy of the Diktat.

Use a lawful copy available to you through the author, institution, library, instructor, or another source that has permission to distribute it. Do not treat an unofficial third-party upload as an official course dependency.

If you do not currently have access to the Diktat, continue with the module explanation, notebook, exercises, and mastery checks. The [Reference Map](REFERENCE_MAP.md) identifies the concepts being traced to the Diktat.

## Reading strategy

For each module:

```text
module README
→ referenced source section when available
→ notebook examples
→ exercises
→ quiz / assignment
→ mastery check
```

Do not postpone hands-on work until every external reading is complete. The readings and executable course materials are intended to reinforce each other.

## Reference discipline

External tutorials, videos, documentation, or AI tools may be useful for personal study, but they do not become additional formal course references merely because a learner uses them.

Required course concepts remain governed by [Source Boundary](SOURCE_BOUNDARY.md).
