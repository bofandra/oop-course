# Instructor Guide

This course can also be facilitated by instructors, mentors, bootcamps, study groups, or internal training programs.

There is no required institutional calendar or fixed session length.

## General facilitation flow

For each module:

```text
Review prior concept
→ introduce the modelling problem
→ explain the new concept
→ live-code or model an example
→ guided practice
→ independent exercise
→ quiz / reflection
→ bridge to the next module
```

## Suggested time allocation

If running a live session, a useful balance is:

| Activity | Approximate share |
|---|---:|
| Review / motivation | 10% |
| Concept explanation | 25% |
| Live coding / modelling | 25% |
| Guided / independent lab | 30% |
| Quiz / reflection / bridge | 10% |

Adjust freely to learner experience and session length.

## Module-specific notes

Each `week-XX/instructor-notes.md` file contains:

- teaching goals;
- concept sequence;
- live-code suggestions;
- common misconceptions;
- scope guardrails;
- assignment grading notes.

Any time labels that once existed in the original classroom version have been removed. The notes now describe sequence and relative emphasis only.

## Assessment

Assessment is optional.

A facilitator may:

- use all quizzes and labs;
- use only selected labs;
- use the mid-course and final assessments;
- use the entire repository as non-graded practice.

See [Grading Operational System](GRADING_SYSTEM.md) if structured grading is desired.

## Public repository safety

Do not publish:

- answer keys;
- real learner gradebooks;
- private learner data;
- executable reference solutions before an assessment if learners are being graded.
