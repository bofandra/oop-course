# Open Course Guide

This repository is an **institution-independent, self-paced open course**.

It has:

- no university affiliation;
- no semester dependency;
- no fixed meeting day or class time;
- no required cohort start/end date.

Anyone may begin at any time.

## How to use the course

The folders `week-01` through `week-16` represent a recommended learning sequence.

They are not calendar weeks.

You may:

- complete one module per week;
- complete several modules in one week;
- spend multiple weeks on a difficult module;
- pause and resume later.

## Recommended prerequisite

Complete Module 0 / Python Primer first if you are not yet comfortable with basic Python.

## Recommended progression

```text
Primer
→ OOP fundamentals
→ relationships
→ inheritance/polymorphism
→ runtime object concepts
→ exceptions/contracts
→ analysis/design/testing
→ reuse/patterns
→ final project
```

## Two ways to use this repository

### Self-paced learner

Use quizzes and assignments as practice and self-assessment.

### Instructor / study group

Use the supplied rubrics, instructor notes, and optional grading system to run a structured cohort at any pace.
