# Week 14 — OOP Analysis, Design, Class Diagram & Testing

## Learning outcome

Transform a requirement into an object-oriented solution through OOA → OOD → OOP → OOT.

## Focus

- requirement → candidate objects
- state, behavior, and responsibilities
- relationships
- minimal class diagram
- contracts
- Python implementation
- testing independent classes
- testing collaborating classes
- testing an end-to-end scenario

## References

- Inggriani Liem, *Diktat Kuliah Pemrograman Berorientasi Objek* — OOA, OOD, OOP, OOT and the case-study section.
- OpenStax supports the Python implementation concepts used in the solution.
