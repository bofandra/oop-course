# Start Here — Object Oriented Programming Open Course

Welcome. This repository is designed so you can start at any time and learn at your own pace.

## 1. Choose your learning mode

### Self-paced

Use the course as an independent learning path.

```text
Python readiness check
      ↓
Module 1–7
      ↓
Mid-course mastery checkpoint
      ↓
Module 9–15
      ↓
Final project
      ↓
Portfolio-ready OOP evidence
```

Use quizzes, exercises, notebooks, assignments, rubrics, and the [Self-Assessment Guide](SELF_ASSESSMENT_GUIDE.md) to decide when to move forward.

### Facilitated cohort / study group

A facilitator may use the same modules with a custom calendar, selected assignments, grading rules, and assessment conditions.

The folder names `week-01` through `week-16` are retained for repository stability. They are module identifiers, not calendar requirements.

## 2. Check your Python prerequisite

If basic Python syntax is still difficult, begin with:

- [Module 0 — Python Primer](00-python-primer/)
- [Python Readiness Check](00-python-primer/readiness-check.md)

You are ready for Module 1 when you can comfortably read and write basic functions, conditionals, loops, lists, dictionaries, parameters, and return values.

## 3. Follow the recommended module sequence

```text
Objects
→ Classes, state & behavior
→ Encapsulation
→ Relationships
→ Inheritance
→ Polymorphism
→ Advanced inheritance structures
→ Runtime object behavior
→ Operator overloading & modules
→ Exceptions & contracts
→ OOA / OOD / OOP / OOT
→ Reusability & patterns
→ Final project
```

See the [Course Map](COURSE_MAP.md) for detailed learning-outcome and assessment alignment.

## 4. Use a mastery rule, not a calendar rule

Move forward when you can explain the core idea, complete a representative exercise, predict and verify example behavior, justify a design decision, and identify what you still do not understand.

## 5. Build evidence as you learn

Keep completed notebooks, selected exercises, coding assignments, design explanations, the mid-course assessment attempt, and the final project as portfolio evidence.
