# Week 13 — Exception Handling & Assertions

## Learning outcome

Raise and handle runtime exceptions, and formulate preconditions, postconditions, invariants, and basic assertions for object behavior.

## Focus

- runtime failure and exceptions
- `raise`
- `try` / `except`
- specific exception handling
- assertions
- preconditions
- postconditions
- class invariants
- Client–Supplier contract thinking

- OpenStax, *Introduction to Python Programming* — 14.4 Handling Exceptions and 14.5 Raising Exceptions.
