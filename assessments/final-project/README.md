# Final Project — Week 16

## Goal

Design, implement, test, demonstrate, and defend a complete object-oriented solution.

The expected workflow is:

```text
Requirement
  ↓
OOA
  ↓
OOD
  ↓
OOP
  ↓
OOT
  ↓
Demo / Viva
```

## Required deliverables

1. `README.md`
2. class diagram
3. Python source code
4. tests
5. individual demo / design explanation

## Suggested rubric

| Component | Weight |
|---|---:|
| Object-Oriented Analysis | 15% |
| Class design & relationships | 15% |
| State, behavior & encapsulation | 10% |
| Inheritance & polymorphism | 15% |
| Contracts & exception handling | 15% |
| Python implementation quality | 20% |
| Testing | 10% |
| **Total** | **100%** |

## Scope

The project should remain focused on OOP. A web UI, database, REST API, or GUI is **not required**.

A good submission should make it possible to trace:

```text
Requirement
  ↓
Design decision
  ↓
Python implementation
  ↓
Test scenario
```
