# Mid Test — Week 8

## Purpose

Assess whether students can integrate Weeks 1–7:

- identify objects;
- assign state and behavior;
- model has-a / is-a relationships;
- apply encapsulation;
- implement inheritance;
- use overriding and polymorphism;
- explain their design.

## Recommended format

One case study:

```text
Case Study
  ↓
Identify Objects
  ↓
Model Classes
  ↓
Implement in Python
  ↓
Explain OOP Concepts
```

Recommended duration: **150–180 minutes**.

## Suggested weighting

| Section | Weight |
|---|---:|
| Object identification | 15% |
| Relationship modelling | 15% |
| Python implementation | 40% |
| Polymorphism reasoning | 15% |
| Concept explanation | 15% |
| **Total** | **100%** |
