# Week 15 — Reusability, Design Patterns & OOP Case Study

## Learning outcome

Explain reuse at code/design level, recognize recurring object-collaboration structures, and complete an end-to-end OOP case study.

## Focus

- code reuse vs design reuse
- pattern as a reusable design idea
- selected Strategy-style example
- selected Factory Method-style example
- end-to-end case study
- reflection on when a pattern helps and when it adds unnecessary complexity

## References

- Inggriani Liem, *Diktat Kuliah Pemrograman Berorientasi Objek* — reusability and pattern terminology.
- OpenStax supports the Python OOP concepts used in the examples.
