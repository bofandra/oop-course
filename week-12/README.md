# Week 12 — Operator Overloading, Genericity & Organizing Classes into Modules

## Learning outcome

Use selected Python dunder methods for operator overloading, explain genericity conceptually, and organize related classes into Python modules.

## Focus

- operator overloading via selected magic/dunder methods
- `__str__`, `__add__`, and `__eq__`
- genericity as type parametrization
- genericity vs inheritance
- modules containing one or more related classes
- imports and aliases

## References

- Inggriani Liem, *Diktat Kuliah Pemrograman Berorientasi Objek* — Overloading and Genericity.
- OpenStax, *Introduction to Python Programming* — 11.4 Overloading Operators and 11.5 Using Modules with Classes.
