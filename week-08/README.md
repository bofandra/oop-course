# Week 8 — Mid Test

## Learning outcome

Integrate concepts from Weeks 1–7 by analysing a new problem, modelling objects and relationships, implementing a Python solution, and explaining the resulting OOP design.

## Scope

The Mid Test covers:

```text
Week 1  Thinking in Objects
Week 2  Classes, Objects & Instances
Week 3  State & Behavior
Week 4  Encapsulation & Abstraction
Week 5  Object Relationships
Week 6  Inheritance
Week 7  Overriding, Polymorphism & Dynamic Binding
```

No new OOP topic is introduced in Week 8.

## Assessment format

The exam uses one integrated case study:

> **Vehicle Rental System**

Students are expected to move through:

```text
Requirement
   ↓
Identify Objects
   ↓
State & Behavior
   ↓
Relationships
   ↓
Python Classes
   ↓
Inheritance
   ↓
Polymorphism
   ↓
Explanation
```

Recommended duration: **150–180 minutes**.

## Assessment weighting

| Section | Weight |
|---|---:|
| A. Identify Objects | 15% |
| B. Model Relationships | 15% |
| C. Python Implementation | 40% |
| D. Polymorphism | 15% |
| E. Concept Explanation | 15% |
| **Total** | **100%** |

The assessment only uses concepts already taught from the two formal course references:

1. Inggriani Liem, *Diktat Kuliah Pemrograman Berorientasi Objek*.
2. OpenStax, *Introduction to Python Programming*.

## Important

The Mid Test is intended to measure object-oriented modelling and implementation, not web development, databases, APIs, GUI programming, or advanced Python features.

Students should solve the problem using the simplest OOP design that satisfies the stated requirements.
