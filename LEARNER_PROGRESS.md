# Learner Progress Tracker

Use this file as a lightweight checklist for the self-paced course.

You can copy this page into your own notes, fork the repository, or recreate the checklist in any tool you prefer. The repository does not store personal learner progress.

## How to use the tracker

For each module:

1. study the README and notebook;
2. complete representative exercises;
3. attempt the quiz;
4. complete the assignment or assessment evidence;
5. attempt the matching [Mastery Checks](MASTERY_CHECKS.md);
6. write one short reflection;
7. mark the module complete when you can **explain, apply, and defend** the core idea.

Use the [Self-Assessment Guide](SELF_ASSESSMENT_GUIDE.md) when you are unsure whether to move forward.

## Major checkpoints

### Before the Mid-Course Assessment

You should be able to model a small problem with objects, give objects meaningful responsibilities, explain object relationships, use inheritance only for meaningful is-a relationships, and demonstrate overriding/polymorphism.

### Before starting the Final Project

After Module 12, read the [Final Project brief](assessments/final-project/README.md) early. Start collecting candidate modelling decisions and questions; you do not need to implement the full project yet.

### Before completing Module 16

Confirm that you can trace:

```text
requirement
→ object-oriented analysis
→ design decisions
→ Python implementation
→ tests
→ explanation / defense
```

Use the [Final Project checklist](week-16/final-project-checklist.md) before considering the course complete.
